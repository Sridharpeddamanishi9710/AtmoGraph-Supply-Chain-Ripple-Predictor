# AtmoGraph: Supply Chain Ripple Effect Predictor

## Overview
AtmoGraph is a machine learning-based project designed to analyze
supply chain data, predict potential disruptions, and simulate
ripple effects across supply chain networks.

## Objectives
- Analyze supply chain datasets.
- Perform data preprocessing and exploratory data analysis.
- Develop machine learning models.
- Analyze supply chain networks.
- Simulate disruption scenarios.
- Visualize results through an interactive dashboard.

## Technology Stack
- Python
- Pandas and NumPy
- Scikit-learn
- NetworkX
- Matplotlib and Seaborn
- Streamlit
- Git and GitHub
